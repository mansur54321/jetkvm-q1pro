# Q1 Pro root filesystem

`build.py` constructs a headless R4 image around the JetKVM ARM application. It reads only the validated software volume from a local factory MTD6 dump and extracts an explicit list of board files. [Build dependencies and installation](../../BUILD.md)

| File | Use |
| --- | --- |
| `q1pro-rootfs.squashfs` | Standard SquashFS for local verification and QEMU |
| `q1pro-rootfs.sfoo` | The same filesystem with the stock superblock format |
| `manifest.json` | Image format, version, geometry and SHA-256 digests |

Boot uses BusyBox, device nodes generated by devtmpfs or mdev, and the existing Linux kernel ABI. JetKVM and `wpa_supplicant` handle networking. Dropbear supports the optional development console with authorized keys. The local build obtains the factory modules, DP audio configuration, wireless firmware and Bluetooth runtime from the reader's board backup.

## Build on Linux

Set `BUILDKIT_PATH` to the JetKVM v0.2.8 ARM buildkit. Download the source archives named below from their upstream distributions.

~~~sh
cache="$HOME/.cache/jetkvm-q1pro/image-tools"
mkdir -p "$cache/bin" "$cache/src"
tools/q1pro-image/build-busybox.sh "$cache/src/busybox-1.37.0.tar.bz2" "$cache/bin/busybox-arm"
tools/q1pro-image/build-dropbear.sh "$cache/src/dropbear-2026.94.tar.bz2" "$cache/bin/dropbearmulti-arm"
tools/q1pro-image/build-wifi.sh "$cache/src" "$cache/wifi"
python3 -B tools/q1pro-image/build.py \
    --mtd6 /path/to/backup/mtd6-rootfs.bin --sdk "$BUILDKIT_PATH" \
    --busybox "$cache/bin/busybox-arm" --dropbear "$cache/bin/dropbearmulti-arm" \
    --wifi "$cache/wifi" --app bin/jetkvm_app --output bin/q1pro-image
~~~

`build-wifi.sh` expects `libnl-3.12.0.tar.gz`, `wpa_supplicant-2.12.tar.gz` and `openssl-3.6.5.tar.gz` in the source directory. The host needs SquashFS tools with XZ support, `readelf` and `qemu-arm`.

## Verify the output

~~~sh
tools/q1pro-image/test-led.sh
tools/q1pro-image/test-wifi.sh bin/q1pro-image/q1pro-rootfs.squashfs
tools/q1pro-image/test-ssh.sh bin/q1pro-image/q1pro-rootfs.squashfs
python3 -B tools/q1pro-image/test-package.py bin/q1pro-image
~~~

For the settings-preserving updater, generate an Ed25519 key and keep its private half on the workstation. Export the public half as a separate trusted file and use `package.py pack` and `package.py verify`. See [maintenance package format](../q1pro-maintenance/README.md) and [virtual NAND tests](../q1pro-sysupgrade/test-flash/README.md).
